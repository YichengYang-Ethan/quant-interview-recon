## 4. Slug traps

**一亩三分地.** `https://www.1point3acres.com/interview/company/{slug}` returns a clean `total=0` for a wrong slug, so a bad slug looks like "no data" instead of an error. Never conclude "no 面经" from a zero until the slug is on the verified list. Verified working slugs and thread totals are in §3. **Verified dead** (return total=0 — do not trust the zero): `hudsonrivertrading`, `hrt`, `susquehanna`, `xtx`, `cubist`, `tower`, `jump`, `oldmission`, `pdtpartners`, `radix`, `jane-street`, `akuna-capital`. For some firms the real slug is a URL-encoded display name with spaces: `/interview/company/Hudson%20River%20Trading`, `/interview/company/Radix%20Trading`, `/interview/company/jump%20trading`. Note `jumptrading` (63) and `jump%20trading` are both live while bare `jump` is dead — check both and merge.

**Glassdoor.** Five Rings = **375785**; `1100190` is *Five Rings Financial* (an insurance MLM) and `4020779` is *Five Rings Aerospace* — a wrong ID here poisons an entire query set. Cubist has **no standalone employer page**; reviews live under Point72 `1032703`, and `6823351` ("Cubist") / `4306586` ("Cubist Pharmaceuticals") are unrelated. D. E. Shaw's entity is literally named "D. E. Shaw & Co. - Investment Firm" (`29290`), distinct from D. E. Shaw Research, the computational-biochemistry firm. Jane Street = `255549`, not `1357498` ("Jane Street Entertainment").

**Greenhouse.** The token `janestreet` **exists and returns 230 jobs, but only internal/recruiter reqs** (e.g. "Campus Recruiter, Technology"). Jane Street's student/NG reqs are not on Greenhouse; a scraper trusting that token silently returns zero candidate-facing roles. Already tested and 404: `hudsonrivertrading`, `wehrt`, `hrtcareers`, `hudsontrading`, `drw`, `drwholdings`, `drwtrading`, `xtxmarkets`, `xtx`, `headlandstech`, `headlands`, `radixtrading`, `radix`, `gresearch`, `towerresearch`, `imctrading`, `citadel`, `citadelsecurities`, `qube`, `millennium`, `balyasny`, `bwater`, `quantlab`, `wolverinetrading`, `belvederetrading`. 200-but-empty: `optiver`, `marshallwace`. The embed URL `boards.greenhouse.io/embed/job_board?for=towerresearch` 404s despite that string appearing in Tower's page HTML.

## 5. Search-string kit

Templates only — every `<token>` must come from §1, never be coined. Substitute one alias per query and run the aliases as separate queries rather than OR-ing them; the abbreviations (`CitSec`, `HRT`, `SIG`, `DESCO`, `QRT`, `OMC`, `CTC`, `MLP`) pull different threads than the full names.

- Chinese forums, non-中文-name firms: `<English alias> 面经`, `<English alias> 量化 OA`, `<English alias> 电面`, `<English alias> 群面`, `<English alias> new grad 面试`.
- Chinese forums, the seven firms with a 中文 token: run both, e.g. `简街 面经` **and** `Jane Street 面经`; `城堡 面经` **and** `Citadel 面经`. The 1point3acres title "城堡 详细跪经+吐槽|citadel面经" shows both tokens co-occurring in one thread, so either query alone loses hits.
- 一亩三分地 tag pages sit at `https://www.1point3acres.com/bbs/tag/<name>` with the space URL-encoded, e.g. `/bbs/tag/imc%20trading`. Thread URLs look like `/bbs/interview/citadel-quant-470966.html`.
- Glassdoor interview pages: `https://www.glassdoor.com/Interview/<Name>-<Role>-Interview-Questions-EI_IE<id>.0,<n>_KO<a>,<b>.htm` — e.g. Quantlab `EI_IE262109.0,8_KO9,30.htm`, Marshall Wace `EI_IE269459.0,13_KO14,37.htm`.
- Disambiguators to bolt on when the plain name is noisy: SIG → `Bala Cynwyd`; Five Rings → `Five Rings LLC` and negate `Financial`/`Aerospace`; Citadel Securities → `CitSec` or `Miami`; D. E. Shaw → `DESCO` and negate `D. E. Shaw Research`; Cubist → pair with `Point72`.
- Role tokens that appear verbatim in the reqs and therefore in 面经 titles: `Graduate QT`, `Campus Full Time 2027`, `2027 Grads`, `Entry Level 2027`, `Junior Quantitative Researcher`, `New Grad`, `Quant Trading Associate – 2027 Start`, `Quantitative Trading Analyst`, `Citadel Associate Program`, `Quant Academy`, `LEaD`, `Investment Associate`.
